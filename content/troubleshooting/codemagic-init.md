## Overview

`codemagic init` is a CLI tool that helps developers set up and work with Codemagic in their projects and coding-agent environments.

It analyzes the project, guides developers through Codemagic configuration, generates the required CI/CD configuration, and can install Codemagic-specific knowledge and skills for supported coding agents.

Repository: [codemagic-init on GitHub](https://github.com/codemagic-ci-cd/codemagic-init)

## What it does ?

* Analyzes projects and detects relevant frameworks, platforms, identifiers, and build configurations.
* Guides Codemagic setup through an interactive configuration flow.
* Generates Codemagic configuration based on the project and selected options.
* Provides Codemagic knowledge to AI agents through Codemagic-specific skills.
* Answers Codemagic-specific questions, including configuration and workflow-related questions.
* Helps troubleshoot Codemagic build issues, such as build failures, signing problems, workflow configuration, and deployment issues.
* Keeps Codemagic skills up to date through the update command.
